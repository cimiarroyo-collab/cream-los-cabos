# Cream Los Cabos MVP

Prototipo independiente y no oficial.

- /club — Cream Club (cliente)
- /hub — Cream Hub (sucursal)

## Desarrollo
npm install
npm run dev

## Cloudflare Pages
Build command: npm run build
Output: dist

El MVP usa localStorage para la demo inicial. La siguiente fase migra pedidos a Cloudflare Workers + D1 para sincronización real entre dispositivos.
